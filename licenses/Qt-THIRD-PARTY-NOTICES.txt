Qt 6.11.2 third-party attribution inventory
============================================

Release artifact scope
----------------------

This package intentionally ships only Qt Core, Qt GUI, Qt Widgets, the Windows
platform/style plug-ins, and JPEG/WebP image format plug-ins. Qt Virtual
Keyboard, QML, Quick, PDF, SVG, Network, OpenGL software rendering, TLS, and
their plug-ins are excluded by the build allowlist.

The authoritative Qt 6.11.2 component notices and full per-component license
statements are linked from:

https://doc.qt.io/qt-6/licenses-used-in-qt.html

The following conservative inventory mirrors the Qt 6.11.2 attribution groups
for the shipped modules. A listed component may be compiled out on Windows;
listing it here does not add code to the package.
