Qt 6.11.2 official attribution source bundle
==============================================

This directory contains the unmodified textual attribution metadata and the
license/copyright files referenced by the Qt Core, Qt GUI, qjpeg, and qwebp
components considered by the Windows build. Files were extracted from official
Qt 6.11.2 source archives. The release build excludes Qt Virtual Keyboard, QML,
Quick, PDF, SVG, Network, OpenGL software rendering, TIFF, and unrelated image
plug-ins.

Source archives:
